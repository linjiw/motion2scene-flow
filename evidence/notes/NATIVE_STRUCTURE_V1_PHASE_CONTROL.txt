that run (including temporal outcomes). Motivation is structural: the uniform-16
grid is not nested in the adaptive arms' uniform-8 starting grid. A gain can arise
from grid phase, without using observed margins or motion bounds.

coarse indices, then repeatedly bisect the widest remaining source-index interval,
with leftmost ties, until 16 distinct frames have been queried. This selection does
not read clearance or labels. Apply the same scores, certificates and metrics.
