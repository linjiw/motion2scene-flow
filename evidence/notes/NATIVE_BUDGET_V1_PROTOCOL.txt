# Fixed candidates, query budgets, abstention, and new source groups

Written before new-reference geometry, new labels, budget curves or stopping
results. Locally frozen exploratory follow-up; no external registration. The
previous 4,500 development pairs remain diagnostic. A separate 20-group cohort
tests transfer relative to this workspace's prior 120 references. These sources
exist in a previously inventoried Kimodo corpus, not a newly collected population
or verified MTC release. No FM, motor encoder or controller is trained/executed.

## Question and decision

Can a fixed-budget analytic candidate checker convert extra temporal queries
into continuous 2 cm clearance certificates without missing brief collision
witnesses? Does motion-bound selection improve over static time-gap refinement
and endpoint-only refinement on source groups absent from our earlier studies?
If certificate coverage remains low, do not treat sparse ranking as a validated
FM safety filter. Distinguish checking supplied references from generating motion
alternatives for a fixed scene: our candidate bank is motion/obstacle pairs.

## Frozen geometry and candidate construction

Normalize source root quaternions and use the prior body-origin scene translation
convention (first pelvis xy; all-body/all-frame min z to .1 m). Keep joint-limit
violations; no clipping, retiming or repair. Audit USD FK against the same MJCF
for every new source frame, with max position <1e-6 m, rotation <2e-6 rad.
Check the already audited geometry and model hashes. No physics steps.

Reuse the archived original motion-event recipe code and training-only scales.
Construct the same 225 obstacle recipes: 5 motion-only anchors ×5 lateral offsets
×3 heights ×3 shape types, with the original velocity/yaw direction rule. Do not
fit scales or anchor rules on new references. Reproduce reference coordinates and
all candidate specs for old references 00679, 00331 and 00623 before processing
the new cohort. These are fixed recipe candidates, without learned probability
selection; no new generator or data-dependent candidate filtering.

New labels use the existing typed full-source-frame geometry and max-depth-8
continuous refinement protocol: primitive overlap is a witness; >.02+tolerance
continuous outer clearance is a pass; otherwise unknown. Store refinement cost,
joint-limit flags, and full-source-frame witness masks for independent diagnosis.
Labels never enter the selector. Candidate positions depend on source motion, not
scene clearance. Full future reference and complete static obstacle are privileged
inputs; this does not implement causal observation-conditioned navigation.

## Query interventions

Budgets are 8,16,32,64 distinct original timestamps, each reading all 45 shapes.
Uniform uses a separate evenly spaced grid at each budget; its grids are not
nested. Time-gap, endpoint and motion-bound start from the same uniform 8 frames
and extend nested traces using the previously specified deterministic rules.
Use a priority queue for incremental selection; require exact 16-frame trace,
score and certificate parity with the previous implementation and old results.
Time-gap bisects the largest time-index interval. Endpoint bisects the interval
with smallest observed endpoint outer margin. Motion-bound minimizes the same
two-endpoint per-shape lower bound and bisects motion-bound mass of its worst
shape. Stable leftmost ties; no unqueried clearance, label or event-score access.

The cumulative variation bound comes from all original root/joint intervals.
Both-endpoint lower bound is (d_left+d_right-B)/2. Check endpoint consistency and
complete support coverage. Learning errors are not certified variation bounds.
Full-motion preprocessing cost is outside the geometry-query budget and reported.

## Outcomes and stopping

For each budget/method/population report: known-witness detection (denominator all
typed witness pairs); certified count and fraction of all candidates; clear-label
certification recall; abstention count; missed witnesses among abstentions. Reject
only with an observed primitive witness; accept only with a continuous certificate;
otherwise abstain. Assert no certificate/witness contradiction and record any new
information on old unknown labels without relabeling the frozen cohort silently.
Ranking top 30% remains a secondary diagnostic, never the strict acceptance rule.

Separately execute early stopping for the three nested methods with maximum 64
frames. Initial eight-frame query is atomic; afterwards stop at the first witness
or continuous certificate. Save real queried counts, decisions and time, and check
against the prefix of the full diagnostic trace. Unresolved at 64 is abstention.
Charge all initial/queried frames, FK/bound preprocessing, selection, geometry and
artifact I/O separately where measurable. Per-method compute measurements are
single-host descriptive batch measurements, not real-time or hardware claims.

For each cohort also report the prespecified subset with 1–5 primitive-overlap
source frames (total across time, not assumed contiguous) using labels only after
selection. Preserve old 00623/cell52 as a disclosed diagnostic, not a fresh test.
